# EmotiChat — sitio web estático

Prototipo educativo para adolescentes de 12 a 17 años. Está hecho con HTML, CSS y JavaScript y puede publicarse gratis en GitHub Pages.

## Archivos
- `index.html`: estructura y contenido.
- `styles.css`: diseño adaptable a móviles y computadoras.
- `app.js`: diario local, orientación emocional y ejercicios guiados.

## Probar en tu computadora
Abre `index.html` en un navegador moderno. No requiere instalación ni servidor para las funciones principales.

## Publicar en GitHub Pages
1. Inicia sesión en GitHub y crea un repositorio público llamado `emotichat`.
2. Sube `index.html`, `styles.css` y `app.js` a la raíz del repositorio.
3. En el repositorio, entra a **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y pulsa **Save**.
6. Espera a que GitHub Pages publique el sitio. La URL tendrá el formato `https://TU-USUARIO.github.io/emotichat/`.

## Cómo funciona el diario
Los registros se guardan en `localStorage` del navegador. No se envían a un servidor ni se sincronizan entre dispositivos. Si se borran los datos del navegador o se cambia de dispositivo, los registros pueden perderse. Evita introducir información que identifique a una persona.

## Alcance y seguridad
- La emoción la selecciona el usuario; el sitio no detecta emociones automáticamente ni analiza rostros, voz o texto.
- Las recomendaciones son educativas y generales; no son diagnóstico ni tratamiento.
- El sitio no es un servicio de emergencia.
- Antes de una presentación pública, revisen los contactos oficiales y las políticas de privacidad con su docente.
- Los enlaces MINSA incluidos apuntan a páginas oficiales consultadas al preparar este prototipo.
